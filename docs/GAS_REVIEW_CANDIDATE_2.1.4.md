# GAS 2.1.4 검토 후보

웹 2.1.4의 저장 고지서 CSV·빈 고지서 보존·미작성 표시를 포함한 로컬 검토용 압축본이다. 기존 입금 원장·청구 기준 대조/정정·분기 집계도 포함한다. 운영 배포와 실제 Google 저장은 수행하지 않았다.

- [파일별 해시와 출처](../releases/gas-candidate-2.1.4.json).

파일은 `App.html`, `AuthorizeDocs.gs`, `Billing.gs`, `CalendarSync.gs`, `Code.gs`, `CurrentStatus.gs`, `IndependentApp.gs`, `appsscript.json`의 8개다. ZIP을 읽어 검증된 제품 파일과 각 바이트를 비교한 후 실행한다. GAS 문법·소유자 전용 공개 범위·배포자 실행·Asia/Seoul 설정을 검사한다. 실제 임대 자료·OAuth 설정·서명키·`.clasp.json`은 포함하지 않는다. 시트·문서·Calendar 대상은 검증한 독립 GAS 소스와 동일하다.

ZIP은 이 컴퓨터에만 생성했으며 Git에서 제외한다. manifest·검증 결과·생성 도구는 로컬 Git에 기록한다. 기존 2.1.3/2.0.6 ZIP과 기록은 같은 해시로 보존했다. 두 번째 패키징 명령은 기존 2.1.4 파일을 검증해 재사용했다.

브라우저 검사 총 44개를 통과했다. 복원 검사에는 PC/모바일 미리보기 취소·적용·재실행·전체 JSON 내보내기, 보관/미등록 임차인을 포함한 저장 고지서와 월별/분기 CSV, 빈 고지서가 채워지지 않는 동작과 6개 화면 크기의 7개 메뉴가 포함된다. 빈 고지서 사례가 실제로 검사되었음을 별도로 기록한다. 모든 화면 검사는 외부 요청을 차단한 별도 Edge 프로필에서 익명 자료로 실행한다.

일반 후보 검사에서 `RENTAL_RESTORE_INPUT`은 전달하지 않는다. 이번 실행은 존재하지 않는 비공개 입력 경로를 부모 환경에 지정한 상태에서도 익명 복원 검사가 통과하고 `privateInput:false`를 기록해 그 경계를 확인했다. 후보 검사 하나라도 실패하면 기존 결과 파일의 통과 표시를 최종 성공으로 수집하지 않는다.

제품 자체의 전체 단위 178개·브라우저 묶음 12개·실제 자료 로컬 복원 6개는 앞선 [2.1.4 제품 검증](../releases/development-2.1.4.json)의 결과다. 이번에는 해당 제품 파일의 해시·커밋 일치를 다시 확인하고 압축본을 검사했으며 전체 제품 회귀를 반복하지 않았다. 이전 실제 자료 검사나 PWA 검사를 ZIP 검사의 일부로 세지 않는다.

## 재실행과 운영 경계

```powershell
npm run check:build
npm run package:gas
npm run test:gas-candidate
```

Node·PowerShell 7과 브라우저 검사에 필요한 Playwright·Edge를 사용한다. 새 라이브러리를 추가하지 않았다. 새 후보는 소스 커밋과 버전별 검증 기록을 요구하며, 기존 ZIP 또는 불완전 후보를 덮어쓰지 않는다. 허용한 8개 파일만 담고 ZIP과 manifest를 함께 변조한 경우도 검증된 제품 소스와 다르면 실행 전에 거절한다.

이 ZIP에는 PWA 정적 파일이 포함되지 않는다. 로컬 HTTP에서 ZIP의 HTML을 실행한 검사는 Google iframe·실제 소유자 로그인·실제 Sheet 저장·Docs 재생성·Calendar 동기화 또는 실제 휴대전화 설치/오프라인을 입증하지 않는다. 운영 반영 전 필요한 데이터 복구 지점·원장 프로토콜·구형 서버 롤백 경계는 [2.1.3 이관 기준](GAS_REVIEW_CANDIDATE_2.1.3.md#이관과-롤백-경계)을 이어받는다.

과거 추정 청구 기준의 원문 확인, 이미 시작한 원장의 기준 변경 정책, 승인된 실제 저장/재조회와 Docs/Calendar 및 기기 검증은 남아 있다. `productionReady`는 false이며 이 검토 후보 생성은 운영 반영 승인이 아니다. 마지막 별도 운영 GET 확인은 [제품 검증 기록](../releases/development-2.1.4.json)의 시각을 따른다. 이번 패키징 단계에서 Google API 호출·실제 쓰기·업로드·배포·원격 push를 수행하지 않았다.

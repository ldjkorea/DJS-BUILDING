# 실제 휴대전화 안정화 후보 검증

대상: S26 / 실제 One UI. 이 문서는 시험 절차이며 실행 완료 증거가 아니다. API35 에뮬레이터 결과와 실제 휴대전화 결과를 구분한다. 운영 자료 저장은 별도 승인 전 실행하지 않는다.

## 자료와 설치 보호

- 기존 4.1.2를 삭제하지 않고 동일 패키지·서명의 후보를 덮어 설치한다. 설치 전후 버전, 최초 설치 시각, 연결 상태와 암호화 보관 자료 유지 여부를 확인한다.
- 처음에는 예시 자료와 승인된 시험 연결만 사용한다. 실제 임대 시트·Calendar·Docs에 시험 기록을 남기지 않는다.
- One UI 사각형·원형 아이콘과 테마 아이콘, 큰 글씨, 세로/가로 화면을 확인한다. 결과에는 OS·앱 버전·화면 크기·일시를 기록한다.

## 연결 및 화면 상태

- 처음 실행과 두 번째 실행의 화면 표시/서버 확인 시간을 각각 기록한다. Wi-Fi와 모바일망을 구분한다. 보관 자료 표시를 최신 서버 조회 완료로 기록하지 않는다.
- 느린 조회 중 다른 메뉴와 상세 화면을 열고, 늦은 응답이 현재 선택과 입력을 덮어쓰지 않는지 확인한다.
- 계약/입금 정정 초안을 작성하고 회전·뒤로가기·앱 재진입 후 원문을 확인한다. 키보드를 띄워 검토/저장 버튼 접근을 확인한다.
- 저장을 연속 두 번 누르거나 연결을 끊는다. 요청을 자동 재송신하지 않으며 결과 불명 상태에서는 새로고침 전 추가 저장이 차단되는지 확인한다.

## 익명 시험 자료의 업무 시나리오

- 1~4층 입주, 5층 공실: 기존 정산과 원 단위로 일치한다.
- 4층 보관/공실: 전기 100,000원 공급가 중 35,000원·35,000원은 임차인, 30,000원은 별도 부담 후보다. 임차인 고지서 생성과 확정은 정책 확인 없이 실행되지 않는다.
- 4층 점유 중 명도: 상태명만으로 공실 처리되지 않는다. 월 중 퇴거/신규 계약은 퇴거일과 비용 부담 종료일 검토가 필요하다.
- PDF 열기·저장·공유: 세금계산서 표시가 바뀌지 않는다. 실제 외부 발급 확인 문구와 별도 확인 동작을 검사한다.
- 당월/익월 납기, 윤년 2월, 12월→1월: 납기 당일은 체납이 아니며 다음 날부터 체납이다. 과거 snapshot과 입금 날짜를 보존한다.
- 부분입금 두 번 후 하나를 사유 정정한다. 원본을 보존한 void가 한 번만 추가되고 재조회한 잔액이 웹과 일치한다. 다른 고지서·이미 취소된 기록은 선택/저장되지 않는다.
- 최신 이력이 없는 백업, 손상된 백업, 조회 이후 다른 기기 저장: 원장 삭제와 충돌 저장을 차단하고 입력을 보존한다.

운영 자료로 최종 확인할 항목과 테스트 과정에서 실제 쓰기가 필요한 항목은 사용자에게 대상·범위·복구 방법을 제시한 뒤 별도로 승인받는다.

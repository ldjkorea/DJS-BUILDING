# NEW RENT STORE Android 4.1.0 앱 내부 업데이트

2026-10-11. Android 4.1.0 / versionCode 5. 계약·정산·PDF·백업 기능은 4.0.0 그대로 유지하고, 설정의 앱 업데이트 버튼에서 APK 다운로드와 Android 설치 화면을 연결했다.

## 처음 설치와 이후 업데이트

[4.1.0 APK를 Drive에서 다운로드](https://drive.google.com/file/d/1nmrhoB0PaefOmhEnU5KvFC2Gd7Gcod7L/view?usp=drivesdk)하여 기존 앱 위에 설치한다. 4.0.0에는 내부 다운로드 기능이 없으므로 4.1.0을 처음 적용할 때는 이 파일을 한 번 받아야 한다. 기존 앱을 삭제하지 않는다.

4.1.0부터는 설정 → **앱 업데이트**를 누르면 새 버전을 조회한다. 더 높은 버전이 있으면 별도 브라우저 없이 다운로드하고 진행률을 표시한다. 파일을 검증한 뒤 Android 설치 화면으로 이어진다. 이미 최신 버전이면 파일을 받거나 설치하지 않는다.

처음에는 Android의 NEW RENT STORE **이 출처 허용 / Allow from this source** 화면이 나타날 수 있다. 사용자가 허용하고 돌아오면 검증 후 설치 화면을 연다. 최종 **업데이트 / 설치** 확인은 Android가 담당한다. 허용이나 설치를 취소하면 앱에서 **설치 계속**으로 다시 진행할 수 있다. 강제·무인 설치를 하지 않는다.

## 파일과 자료 보호

- 다운로드 위치와 요청은 기존 고정 HTTPS Android API에 한정한다. 다른 다운로드 URL, Drive 파일 ID 또는 임대 자료를 호출자가 지정할 수 없다.
- SHA-256, 정확한 크기, 배포 버전, 앱 패키지와 기존 설치본의 서명을 검증한다. 현재 서명과 APK 서명 모두 고정 인증서와 같아야 한다. 손상·다른 앱·다른 서명·동일 또는 낮은 버전은 설치 단계에 도달하지 못한다.
- 최대 16MiB APK, 64개 이하 구간을 허용한다. 각 구간의 버전·해시·번호와 길이를 확인한다. 내려받는 중 배포가 바뀌면 실패하며 재시도를 안내한다.
- 앱 전용 임시 파일에 받으며 검증을 통과한 APK만 설치에 제공한다. 실패·취소 시 임시 파일을 제거하고 임대 자료는 읽거나 쓰지 않는다.
- 설치기에는 APK 전용 디렉터리의 content URI와 임시 읽기 권한만 제공한다. 연결 토큰·임대 캐시·백업 파일 디렉터리는 제공하지 않는다.
- 다운로드 상태는 화면 회전 동안 유지한다. 프로세스가 종료되거나 설치 허용 화면에서 돌아오는 경우에도 설치 전에 파일을 다시 검증한다.
- Android `REQUEST_INSTALL_PACKAGES` 권한을 선언했다. 새 런타임 라이브러리와 저장소 전체 접근 권한은 추가하지 않았다.

## APK 배포 경로

GitHub 저장소는 계속 비공개이며, APK에 GitHub 토큰을 넣지 않는다. 기존 Android GAS 게이트웨이에 서명된 APK만 포함한 배포 파일을 추가했다. `androidUpdateManifest` GET은 버전·크기·해시를, `androidUpdateChunk` GET은 해당 배포의 APK 구간만 반환한다. 임대 자료 POST의 기기 승인·잠금·조건부 저장은 그대로다. APK 다운로드에는 기기 연결이나 Drive 로그인이 필요 없다.

소유자 GAS·라이브러리는 버전 12, Android API 배포는 버전 5다. 기존 Sheets·Docs·Calendar 범위는 유지하며 Drive 접근 권한은 추가하지 않았다. 원래 RENT STORE, 2025 RENT STORE와 웹 2.3.0의 화면·저장 규칙은 변경하지 않았다.

후속 APK를 배포할 때는 같은 패키지·서명과 증가한 versionCode를 유지하고, 완성 APK로 다음 파일을 생성한다.

```text
node scripts/package-android-update.cjs releases/NEW-RENT-STORE-VERSION.apk VERSION CODE SIGNER_SHA256 .private/AndroidRelease.gs
```

생성한 `AndroidRelease.gs`를 게이트웨이의 Code·appsscript와 함께 하나의 새 버전에 배포한다. 소유자 업데이트 메타데이터와 라이브러리 버전도 맞추고, 실제 GET으로 전체 APK를 다시 내려받아 원본 해시를 비교한다. 생성 파일은 공개 소스에 커밋하지 않으며 APK와 manifest는 릴리스 자산으로 보관한다. 공개 응답에는 APK·배포 정보만 포함된다.

## 검증 범위

- Node 검사 221개 통과. APK 전송 구간의 완전성·배포 변경 거부·범위 제한과 임대 서비스 미호출을 포함한다.
- Android release 빌드·단위 검사·lint 통과. lint 오류 0, 기존 경고 6.
- Android 계측 11개 통과. 실제 업데이트 전후에 별도로 실행해야 하는 2개 검사는 일반 실행에서 건너뛰고, 아래 실제 설치·자료 보존 검증으로 각각 통과했다.
- API 35 전용 에뮬레이터에서 정상 서명의 다음 버전 APK, 손상·크기 오류·버전 오류·다른 서명, 잘못된 구간·취소와 암호화 임대 보관 파일 불변을 확인했다.
- 실제 배포에서 APK 8개 구간을 다운로드한 결과가 원본 3,066,923바이트와 완전히 동일했다. 오래된 배포 번호 요청은 거부됐다.
- 업데이트 기능을 포함한 code4 테스트 설치본에서 실제 Google 다운로드 → Android 설치 허용 → 설치 확인 → 최종 서명 release code5 설치를 수행했다. 기존 stock 4.0.0에 내부 다운로드 기능이 있다는 의미는 아니다.
- 설치 후 실제 설치 APK 해시가 배포 해시와 같고 암호화 캐시 바이트와 모의 임대 자료가 유지됨을 확인했다. 최초 설치 시각 2026-10-11 05:49:30도 유지됐다.
- Drive 업로드의 크기와 SHA-256은 원본 APK와 동일하다. 기존 Drive APK의 공유·파일은 변경하지 않았다.
- 실제 운영 임대 자료 쓰기는 수행하지 않았다. 실물 휴대전화 및 제조사별 설치 정책은 미검증이다.

검증 결과는 `releases/android-4.1.0.json`과 `releases/native-4.1.0-validation.json`에 기록한다. 기존 4.0.0 업무 안내는 `ANDROID_NATIVE_4.0.0.md`를 따른다.

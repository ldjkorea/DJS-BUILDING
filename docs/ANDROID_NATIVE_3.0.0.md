# NEW RENT STORE Android 3.0.0

2026-10-10, Android 3.0.0 / versionCode 3. 기존 웹 2.3.0은 같은 주소와 자료를 유지한다. 2.x의 브라우저 실행기를 Kotlin Android Views로 교체했다. 화면에는 번들 Pretendard 글꼴을 사용하며 OFL 라이선스를 APK에 포함한다.

## 설치와 최초 연결

1. [Google Drive APK](https://drive.google.com/file/d/1jmPpLhqla_LxGVmC0ZNseymgkEEkpssu/view)를 내려받아 설치한다. 기존 앱을 삭제하지 않고 같은 서명으로 업데이트할 수 있다.
2. 앱 설정에서 Google 계정으로 기기 연결을 시작한다. 기존 NEW RENT STORE 소유자 계정으로 열리는 연결 승인 페이지에서 승인한다.
3. Android 앱으로 돌아가기를 누른다. 자동 복귀가 안 되면 5분 안에 연결 코드를 앱의 코드 입력에 붙여넣는다. 연결을 시작한 기기의 검증값이 있어야 한다.
4. 최초 조회가 성공하면 실제 임대 자료를 표시한다. 예시 모드는 별도 표시하며 실제 자료를 저장하지 않는다.

앱 설정의 업데이트 확인은 공개 버전 정보만 조회한다. 새 버전이 있으면 비공개 GitHub 최신 릴리스에서 APK를 내려받아 Android 설치 확인을 거쳐 적용한다. 해당 GitHub 계정 로그인은 필요할 수 있다. 무인 설치는 제공하지 않는다. 이후 릴리스에는 같은 패키지·서명을 유지하고 versionCode를 증가시키며, GAS 버전 정보와 실제 릴리스 APK를 함께 맞춘다.

## 네이티브 기능 범위

- 홈: 월별 청구·수납·미수납, 전체 연체액, 세입자·계약 기한, 지출 조회와 추가.
- 세입자: 이름·상호·호실 검색, 계약·금액·수납 상태·최근 이력과 전화 연결.
- 고지서: 저장된 월별 고지서의 항목·잔액·이력, 실제 입금 날짜에 따른 월세/관리비 완납과 취소, 웹에서 개시한 원장의 항목별 부분입금.
- 설정: 새로고침, 기기 연결·해제, 버전 확인, 임대현황 문서 재생성·계약 Calendar 동기화, 외부 문서와 PC 도구 열기.

고지서 신규 작성과 정산, 계약 변경, 원장 개시·청구 기준 검토, 인쇄·백업 등 고급 업무는 유지한 웹 도구에서 처리한다. 로그인 승인·외부 Google 문서·APK 다운로드도 사용자가 선택하면 브라우저를 연다. 일반 홈·세입자·고지서 화면은 Android 화면으로 실행한다.

## 기존 데이터와 보안

소유자 전용 `NEW RENT STORE - GAS`를 불변 버전 8 라이브러리로 공유하는 별도 `NEW RENT STORE - Android API` 프로젝트를 배포했다. 기존 웹 배포는 `MYSELF`, 새 JSON 게이트웨이만 `ANYONE_ANONYMOUS`다. 익명 호출은 버전 정보만 제공하며, 임대 자료는 승인된 기기 토큰이 있어야 읽고 쓸 수 있다. 게이트웨이는 HTML이나 임의 라이브러리 함수를 제공하지 않는다.

5분·1회용 연결 코드는 기기가 생성한 검증값의 SHA-256과 결합한다. 서버에는 기기 토큰 원문 대신 해시를 보관한다. 기기 연결은 180일 유효하고 최대 8대다. 앱 토큰과 조회 캐시는 Android Keystore AES-GCM 및 AtomicFile로 암호화하며 백업과 평문 HTTP를 차단한다. APK에 운영 비밀키를 넣지 않는다.

같은 라이브러리의 Script Properties·잠금·저장 함수를 사용한다. 기존 expectedRevision, 요청 ID, 복구 백업, 저장 후 조회 확인과 청구 계산을 재사용하며 미지 필드를 보존한다. 웹과 다른 기기의 수정 충돌은 새로고침을 요구한다. 결과가 불확실한 저장은 자동 재전송하지 않는다. 오프라인 캐시는 조회만 가능하고, 최신 자료 조회가 성공하기 전에는 저장하지 않는다. DB 저장 성공 후 Docs 갱신 실패는 별도 결과로 유지한다.

## 검증과 제한

- 단위 검사 203/203, 전체 브라우저 15개 묶음 통과.
- Android release 빌드·lint·단위 검사 통과. lint 오류 0, 경고 2: 기존 UI Automator 버전 안내와 고정 ISO 날짜 문자열 표시.
- 전용 API 35 에뮬레이터에서 3개 계측 흐름 통과: 자동 브라우저 실행 방지·탭/검색/회전, 암호화 오프라인 캐시, 검증값 없는 연결 코드 거부.
- 기존 2.3.0 설치에 3.0.0을 덮어 설치하고 firstInstallTime 유지 확인. 기존과 같은 서명 인증서 확인.
- 새 Google 권한 승인 후 실제 API 버전 GET과 인증 없는 자료 POST 차단을 확인했다. 실제 소유자 연결·자료 조회 및 테스트 기기 해제 결과는 릴리스 검증 JSON에 기록한다.
- 실제 운영 시트의 A1:A1000 값 배열은 배포 전후 동일하다. 원래 RENT STORE와 2025 RENT STORE 저장소는 수정하지 않았다.
- 실제 임대 금액을 쓰는 저장·문서 재생성·Calendar 갱신은 이 검증에서 실행하지 않았다. 실제 저장 경로는 모의 서버 검사로 검증했다. 실물 휴대전화의 Google 복귀와 설치·실제 저장은 미검증이다.

APK와 검증 기록은 `releases/android-3.0.0.json`, `releases/native-3.0.0-validation.json`을 따른다. 이전 2.x 실행기와 APK 기록은 이력으로 보존한다.

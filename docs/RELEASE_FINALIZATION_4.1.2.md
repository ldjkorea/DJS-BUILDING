# Android 4.1.2 / 웹 2.3.1 최종 검사 보완

2026-10-11 사용자 요청으로 중단 후 상태를 조사했다. 새 아이콘·4.1.2 APK·앱 내부 업데이트·Google Drive·GitHub 릴리스는 반영됐고 두 작업 폴더의 미커밋 변경은 없었다. 마지막 GitHub 자동 검사는 이후 실패했다.

## 확인한 문제와 수정 범위

- 두 실행은 모든 브라우저 검사 15개 묶음과 PDF 5종·18페이지를 통과한 뒤 생성 파일 일치 검사에서 실패했다. Windows 체크아웃의 SVG 줄바꿈이 base64로 그대로 들어가 HTML이 4바이트 달라지는 원인을 파일 변경 없이 재현했다. SVG 체크아웃을 LF로 고정하고 빌드에서도 줄바꿈을 정규화했다. LF·CRLF 입력의 최종 HTML이 같은지 회귀 검사를 추가했다.
- 다른 실행은 PWA의 모든 창을 닫은 뒤 다시 여는 단계에서 30초 시간 초과가 있었다. 관찰용 페이지에서 대기 중인 새 서비스 워커를 직접 기록하고, 그 워커의 활성화·새 캐시 존재·이전 캐시 삭제를 확인한 뒤 앱 창을 연다. 관찰용 페이지는 앱 준비가 끝난 뒤 닫는다. 기존의 초안 보존·다른 창 보호·오프라인·다른 앱 캐시 보존 조건과 제한 시간은 유지했다.

앱 실행 코드·Android 소스·GAS·임대 데이터는 변경하지 않는다. 기존 4.1.2 APK와 웹 2.3.1 운영 배포를 유지한다. 새 APK 설치나 운영 데이터 저장은 필요하지 않다.

## 검증 기록

최종 로컬 전체 검사와 GitHub 검사 결과는 완료 후 이 문서 및 `releases/release-finalization-4.1.2.json`에 기록한다. 실제 S26의 One UI 표시와 인증된 초기 조회 속도는 별도의 물리 기기 확인 범위다.

# Android 4.1.2 / 웹 2.3.1 최종 검사 보완

2026-10-11 사용자 요청으로 중단 후 상태를 조사했다. 새 아이콘·4.1.2 APK·앱 내부 업데이트·Google Drive·GitHub 릴리스는 반영됐고 두 작업 폴더의 미커밋 변경은 없었다. 마지막 GitHub 자동 검사는 이후 실패했다.

## 확인한 문제와 수정 범위

- 두 실행은 모든 브라우저 검사 15개 묶음과 PDF 5종·18페이지를 통과한 뒤 생성 파일 일치 검사에서 실패했다. Windows 체크아웃의 SVG 줄바꿈이 base64로 그대로 들어가 HTML이 4바이트 달라지는 원인을 파일 변경 없이 재현했다. SVG 체크아웃을 LF로 고정하고 빌드에서도 줄바꿈을 정규화했다. LF·CRLF 입력의 최종 HTML이 같은지 회귀 검사를 추가했다.
- 다른 실행은 PWA의 모든 창을 닫은 뒤 다시 여는 단계에서 30초 시간 초과가 있었다. 관찰용 페이지에서 대기 중인 새 서비스 워커를 직접 기록하고, 그 워커의 활성화·새 캐시 존재·이전 캐시 삭제를 확인한 뒤 앱 창을 연다. 관찰용 페이지는 앱 준비가 끝난 뒤 닫는다. 기존의 초안 보존·다른 창 보호·오프라인·다른 앱 캐시 보존 조건과 제한 시간은 유지했다.

앱 실행 코드·Android 소스·GAS·임대 데이터는 변경하지 않는다. 기존 4.1.2 APK와 웹 2.3.1 운영 배포를 유지한다. 새 APK 설치나 운영 데이터 저장은 필요하지 않다.

## 검증 기록

- 로컬 `npm run test:all`: 빌드·생성 파일 검사·문법 검사, Node 226개, 브라우저 15개 묶음 모두 통과했다. 전체 감사 69개 사례가 중복 없이 포함됐다.
- 수정한 PWA 6개 항목은 독립 실행 두 번과 전체 실행에서 모두 통과했다.
- PDF 검사는 Codex에 포함된 Python으로 실행해 5종·18페이지의 금액·기록·용지 크기·페이지 밖 텍스트를 확인했다. 기본 시스템 Python에는 pdfplumber가 없어 처음 PDF 실행은 실패했고, 기존 포함 런타임으로 다시 실행해 통과했다. 앱 의존성을 추가하지 않았다.
- [GitHub 자동 검사 38141477497](https://github.com/ldjkorea/NEW-RENT-STORE/actions/runs/38141477497): 소스 `4dcc088e1a46489e229773b5e1261752a2bfc9bd`에서 단위 226개·브라우저 15개 묶음·감사 69개·PDF 5종/18페이지 및 생성 파일 일치 검사 모두 통과했다. 저장된 CI 산출물도 내려받아 확인했다.
- Drive APK와 공개 업데이트 안내를 다시 조회했다. 4.1.2 / 코드 7, 3,257,945바이트, SHA-256 `e0d22e20552fae3393d181880b41df3c5ddc7d4860475ac5e01926bea0b0a273`으로 기존 발행 파일과 같다.

기계가 읽을 수 있는 결과는 [`releases/release-finalization-4.1.2.json`](../releases/release-finalization-4.1.2.json)에 보관한다. 발행된 v4.1.2 태그와 APK는 유지하고, 이후 빌드·검사 수정은 기본 브랜치에 기록했다. 이 문서와 결과 파일을 정리하는 커밋은 문서만 바꾸므로 `[skip ci]`로 중복 검사를 생략한다.

실제 S26의 One UI 표시와 인증된 초기 조회 속도는 이번 작업에서 확인하지 않았다. 이전 API35 에뮬레이터의 내부 업데이트·자료 보존 결과는 기존 릴리스 검증 기록에 있으며, 이번에 재실행한 것으로 표기하지 않는다.

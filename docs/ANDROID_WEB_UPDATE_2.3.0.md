# NEW RENT STORE 2.3.0 웹·Android 업데이트

웹앱은 기존 소유자 전용 GAS 주소를 유지하고, Android는 같은 패키지 `kr.henry.rental.independent`와 기존 release 서명으로 버전 코드 2를 사용한다. 원래 RENT STORE와 2025 RENT STORE의 소스·배포·Google 파일에는 쓰지 않는다.

## 사용 방법

- 웹 설정의 **업데이트 확인**은 GAS의 `getAppUpdateInfo()`로 버전만 조회한다. 시트·문서·Calendar를 읽거나 쓰지 않는다. 실행 시와 앱으로 돌아올 때에도 확인하며, 입력 중 화면을 자동으로 바꾸지 않는다.
- **최신 버전으로 열기**는 초안 보관과 저장 상태 확인 후 기존 운영 주소를 최상위 창에서 연다. GAS iframe만 새로고침하여 오래된 화면을 다시 여는 일을 피한다.
- 저장/조회 중, Google 미반영 수정, 저장 실패, 다른 창 충돌, 열린 입력 창, 미저장 수리 기록은 적용을 막는다. 고지서·정산 초안과 마지막 작업 위치를 보관하며 보관 실패 시 화면을 유지한다.
- 자체 정적 호스트의 PWA에서는 새 worker를 확인하고 사용자가 적용한다. 다른 앱 창이 열려 있으면 적용을 미룬다. 새 worker의 제어권 전환 후 다시 열고, 캐시 정리는 독립앱의 현재 scope에 한정한다. 운영 GAS에서는 서비스 워커를 등록하지 않는다.
- Android의 **APK 업데이트 확인 · 다운로드** 및 웹의 **Android APK · 업데이트**는 비공개 GitHub의 최신 릴리스를 연다. 저장소 접근 권한이 있는 GitHub 계정으로 로그인한 뒤 APK를 내려받고 Android 설치 확인을 진행한다. 웹 화면만 변경하면 APK 재설치는 필요 없다.

## 배포와 후속 버전

- 설치본과 GAS ZIP은 `v2.3.0` GitHub 릴리스에서 제공한다. 인증 정보나 설치 권한은 APK에 추가하지 않았다. 브라우저가 인증과 다운로드를 담당한다.
- 후속 웹 버전은 `package.json`, 화면·클라이언트·GAS 응답·worker 버전을 함께 갱신해 기존 GAS 배포 ID에 연결한다. Git push만으로 GAS가 자동 배포되지는 않는다.
- 후속 APK는 패키지와 기존 비공개 서명키를 유지하고 `versionCode`를 증가시킨다. 공개 릴리스의 최신 링크가 새 설치본으로 이어진다. 원격 키·토큰이나 서명 비밀번호는 공개 파일에 포함하지 않는다.
- 이전 2.0.0 APK·이력과 웹 2.2.2 GAS 버전 6은 보존한다. 필요하면 기존 배포를 버전 6으로 되돌릴 수 있으며, 자료 초기화는 하지 않는다.

## 검증 범위

PC 1366px·모바일 390px에서 버전 확인, 새 버전 안내, 적용 전 보호, 실패·오프라인 재시도를 검증한다. PWA는 실제 worker 설치·오프라인 저장·다중 창 보호·버튼 적용·초안 복원을 확인한다. Android는 release 빌드·린트·단위 검사와 서명 검증, 전용 에뮬레이터의 기존 2.0.0에서 2.3.0으로 무삭제 업데이트를 확인한다.

전체 검증 결과와 실제 운영 배포·시트 대조 결과는 `releases/development-2.3.0.json`, `releases/operating-deployment-2.3.0.json`에 기록한다. 실제 휴대전화에서 Google 로그인·다운로드·설치 확인을 사용자가 수행한 결과는 별도이며, 이번 에뮬레이터 결과와 구분한다.

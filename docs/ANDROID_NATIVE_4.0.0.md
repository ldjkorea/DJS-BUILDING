# NEW RENT STORE Android 4.0.0

2026-10-11. Android 4.0.0 / versionCode 4. 계약 변경, 공용 비용 정산, 출력과 백업·복원을 Android 화면으로 추가했다. 기존 웹 2.3.0과 동일한 독립 GAS·시트 자료를 사용한다.

## 설치와 업데이트

[Google Drive APK](https://drive.google.com/file/d/1wpWEZDbJNpURIEWbTAa5NtHzeghobDwI/view?usp=drivesdk)를 내려받아 기존 앱 위에 설치한다. 패키지와 서명은 3.0.0과 같으며, 전용 에뮬레이터에서 삭제 없이 업데이트한 후 최초 설치 시각 유지도 확인했다. 기존 앱을 삭제할 필요가 없다.

기기 연결이 유지되면 바로 새로고침해서 사용한다. 처음 연결할 때는 설정의 Google 계정으로 연결을 이용한다. 버전 확인과 최신 APK 다운로드 버튼을 유지했으며 이후 APK도 같은 서명과 증가한 versionCode를 사용한다. APK 설치에는 Android 설치 확인이 필요하다.

## 앱 내부 업무

| 업무 | 위치와 동작 |
| --- | --- |
| 계약 변경·재계약 | 세입자 상세 또는 설정 → 계약 변경·재계약. 호실, 기간, 보증금, 월차임, 관리비 항목, 납입일·사용기간 등의 조건과 적용일·사유를 검토하고 저장한다. 변경 전후 조건을 이력으로 남기고 과거 고지서 기준을 보존한다. |
| 공용 비용 정산 | 홈 또는 설정 → 공용 비용 정산. 전기·수도·승강기·오물비, 계량기·사용량을 입력하고 기존 계산기로 배분을 미리본다. 수도·승강기·오물비의 수동 배분은 재검토하며 합계가 일치해야 확정한다. 정산 확정으로 고지서를 생성한다. |
| 고지서 발행·원장 시작 | 고지서 상세에서 발행 표시와 입금 원장 개시 화면으로 이동한다. 추정된 과거 청구 기준은 확인 표시를 요구하며, 원장 개시 후에는 기존 항목별 입금 화면을 사용한다. |
| 출력 | 고지서 상세 또는 설정 → 고지서·정산 출력. 개별·전체 월별 고지서, 확정 정산표, 조회 월이 속한 분기 집계 PDF를 앱 내부에서 미리보고 저장·인쇄한다. 여러 페이지와 긴 한글 기록을 자동으로 나눈다. |
| 백업·복원 | 설정 → 백업·복원. 웹과 호환되는 JSON 백업 파일을 Android 파일 선택기로 저장·불러온다. 원본 운영 자료와 미지 필드를 포함하고 SHA-256 무결성 정보도 웹의 내보내기 전용 메타데이터 위치에 기록한다. 웹에서 불러와 편집하고 다시 내보내는 경우에도 오래된 무결성 정보가 운영 자료에 남지 않는다. 복원 미리보기 후 별도 확인을 거쳐 저장한다. |

업무 화면에서 웹앱으로 이동하는 버튼은 제거했다. Google 소유자 연결 승인, 외부 Google 문서, 전화와 APK 다운로드는 기존 외부 앱 연결을 사용한다. PDF 저장·JSON 파일 선택·인쇄는 Android 기본 파일 선택기와 인쇄 서비스를 사용하며 웹으로 이동하지 않는다.

## 저장과 자료 보호

- 정산은 기존 `RentalBilling.calculate/reconcile`과 부가세·원 단위 배분 규칙을 재사용한다. 전기 2·3층 공급가 35,000원 고정, 4층 잔액 배분을 유지한다.
- 계약 변경 전 기존 고지서 기준을 동결한다. 원장이 있는 고지서의 청구 기준과 원장 기록은 변경하지 않는다. 정산 금액이 바뀐 항목의 납부 상태만 기존 규칙으로 재확인한다.
- 정산 미리보기와 복원 미리보기는 조회 당시 자료의 revision과 검토한 내용에 묶인다. 이후 웹·다른 기기에서 변경하면 저장을 차단한다.
- 모든 저장은 기존 잠금, expectedRevision, requestId, 저장 전 복원 지점과 저장 후 조회 확인을 사용한다. 불확실한 저장은 자동 재전송하지 않는다.
- 기존 입금·계약 변경 이력을 삭제하거나 바꾸는 백업은 복원을 차단한다. 손상 원문과 미확정 웹 초안이 포함된 파일도 확정 자료로 자동 변환하지 않는다. 파일을 보관하고 웹 초안을 별도로 정리한 뒤 확정 자료 백업을 사용한다.
- 현재 파일 읽기 한도는 1.5MB, 중첩 한도는 32다. 이번 실제 운영 백업은 약 94KB이며 무결성·복원 미리보기 검사가 통과했다.
- 기기 토큰, 조회 캐시, 계약·정산 입력 초안과 가져온 백업은 기존 Keystore AES-GCM 암호화 저장소로 보관한다. OS 자동 백업과 평문 HTTP는 계속 차단한다.
- DB 저장 성공과 Docs 갱신 실패를 별도로 표시하며 문서 재생성은 기존 설정에서 다시 시도한다.

## 배포와 검증

기존 소유자 전용 GAS 배포와 라이브러리는 버전 10, 같은 Android API 주소의 배포는 버전 3다. API 라이브러리는 10에 고정하고 Google 접근 범위는 기존 Sheets·Docs·Calendar를 유지했다. 웹 HTML과 웹 버전 2.3.0은 동일하다. 원래 RENT STORE와 2025 RENT STORE는 수정하지 않았다.

- 서버 단위 검사 217/217. 신규 네이티브 API 검사 24개에 계약 동결, 배분·소수 계량기, 납부 상태, 원장 보호, 백업 호환·무결성·이력 보호와 출력 검증을 포함한다.
- 기존 웹 브라우저 15개 묶음 통과. 실제 웹 PDF 5개·18페이지의 금액·페이지 범위 검증 통과.
- Android release 빌드, lint, 단위 검사 통과. lint 오류 0, 경고 6: 기존 테스트 의존성 안내와 문자열 현지화 안내.
- API 35 전용 에뮬레이터 계측 검사 7개 통과. 앱 내부 화면, 계약 입력 회전 복원, 암호화 캐시, 승인 검증값, 파일 인코딩·크기·중첩 차단, 내부 PDF 이동·회전과 선택 페이지 인쇄 파일을 확인했다.
- 긴 한글 PDF 6페이지에서 140개 행과 긴 메모 마지막 문구의 텍스트 추출·표시를 확인했다.
- 실제 소유자 연결 후 조회·백업·복원 미리보기·정산 미리보기·월별 및 분기 출력 응답을 확인했다. 시험 기기를 해제한 뒤 조회 거부도 확인했다.
- 실제 시트 A1:A1000 값은 배포·조회 검증 전후 동일하다. 실제 임대 저장·복원·고지서 발행·Docs/Calendar 갱신은 실행하지 않았다. 쓰기 경로는 모의 서버로 검증했다.
- 실물 휴대전화 설치와 실제 프린터 인쇄는 미검증이다.

APK 정보는 `releases/android-4.0.0.json`, 검증 근거는 `releases/native-4.0.0-validation.json`에 기록한다. 이전 APK와 배포 기록은 보존했다.
